# Intent: Knowledge Pipeline

- **Outcome (결과물)**: 로컬 LLM을 활용해 Gmail/Drive의 민감한 개인정보를 안전하게 검색·취합하여 Obsidian이나 Notion 등 외부 지식 베이스로 정리해 주는 개인화된 데이터 파이프라인 및 고도화된 UI.
- **User (사용자)**: 민감한 개인 데이터를 안전하게 다루고 자신만의 지식 베이스를 구축하려는 사용자(본인).
- **Why now (배경)**: 현재의 MVP는 단순 RAG 검색만 가능하며, 가져온 원본 데이터가 채팅창에 정돈되지 않은 형태로 출력되어 내용을 파악하고 활용하기가 너무 불편하기 때문.
- **Success (성공 기준)**: 사용자가 채팅으로 특정 주제의 정리를 요청하면, 앱이 관련 메일/문서를 깔끔한 카드나 미리보기 형태의 UI로 보기 좋게 제공하고, 로컬 LLM이 이를 요약 및 가공하여 지정된 지식 베이스(Obsidian/Notion)에 성공적으로 내보내는 것.
- **Constraint (제한 사항)**: 프라이버시 보호를 위해 초기 정보 수집 및 정리(가공) 과정은 반드시 로컬 LLM을 통해 이루어져야 함.
- **Out of scope (범위 외)**: 백그라운드에서 주기적으로 전체 이메일을 알아서 동기화하는 완전 자동화 시스템(현재는 채팅 명령 기반), 혹은 이메일 클라이언트 자체를 완벽히 대체하는 기능.
